Durante este curso aprendí que la tecnología puede fortalecer la participación ciudadana mediante herramientas digitales. Comprendí cómo funcionan las bases de datos para almacenar información de forma organizada. Aprendí a crear servidores con Node.js y Express para gestionar información. También entendí la importancia de automatizar procesos con herramientas como n8n y Telegram. Conocí la necesidad de proteger los datos personales y recopilar solo la información necesaria. Además, aprendí a utilizar Git y GitHub para controlar versiones de un proyecto. Finalmente, comprendí cómo integrar todos estos elementos para desarrollar soluciones útiles para las comunidades.
